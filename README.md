# thingsboard_pe_client (discontinued)

**This package is deprecated and no longer maintained.** ThingsBoard CE and PE are now a single product, and
`thingsboard_pe_client` has been replaced by [`thingsboard_client`](https://pub.dev/packages/thingsboard_client)
([GitHub](https://github.com/thingsboard/dart_thingsboard_client)).

Version 5.0.0 of this package contains no code of its own: it only re-exports `thingsboard_client: ^5.0.0`, so
existing code written for `thingsboard_pe_client` 4.4.x keeps compiling while your IDE shows deprecation diagnostics.
This includes deep imports (`package:thingsboard_pe_client/src/...`), which are served by deprecated stub libraries.

> The API is the same OpenAPI-generated API as in 4.4.x. A few model fields changed type (for example
> `AliasEntityId.entityType` is now `String`); see the [CHANGELOG](CHANGELOG.md). Code written for 4.2.x or
> earlier (`getUserService()`, ...) was already broken by 4.4.0 and must be migrated to the generated API.

## Migration

1. In `pubspec.yaml`, replace the dependency:

   ```yaml
   dependencies:
     thingsboard_client: ^5.0.0   # was: thingsboard_pe_client: ^4.x
   ```

2. Rewrite the imports:

   ```sh
   grep -rl "package:thingsboard_pe_client/" lib test | xargs sed -i 's#package:thingsboard_pe_client/thingsboard_pe_client.dart#package:thingsboard_client/thingsboard_client.dart#g; s#package:thingsboard_pe_client/#package:thingsboard_client/#g'
   ```

3. Fetch dependencies and check the result:

   ```sh
   flutter pub get && flutter analyze
   ```

The sed command above also rewrites deep imports (`package:thingsboard_pe_client/src/...`) to the same paths in
`thingsboard_client`.

## Stub libraries

`lib/src/**` is generated by `tool/gen_stubs.sh` (one deprecated re-export per library of
`package:thingsboard_client/src`). This package is frozen at 5.0.0, so the stubs are generated once and do not need
to be regenerated for later `thingsboard_client` releases: users of the old package never import files that did not
exist in 4.4.x.

Please file issues at the [thingsboard_client issue tracker](https://github.com/thingsboard/dart_thingsboard_client/issues).
