# thingsboard_pe_client (discontinued)

**This package is deprecated and no longer maintained.** ThingsBoard CE and PE are now a single product, and
`thingsboard_pe_client` has been replaced by [`thingsboard_client`](https://pub.dev/packages/thingsboard_client)
([GitHub](https://github.com/thingsboard/dart_thingsboard_client)).

Version 5.0.0 of this package contains no code of its own: it only re-exports `thingsboard_client: ^5.0.0`.
REST code written for `thingsboard_pe_client` 4.4.x mostly keeps compiling with deprecation diagnostics, including
deep imports (`package:thingsboard_pe_client/src/...`) of files that still exist in `thingsboard_client`.

> **Breaking changes.** The telemetry WebSocket API and the login models (`LoginRequest`, `LoginResponse`,
> `RefreshTokenRequest`) now use the generated built_value models, so their syntax changed (for example
> `DeviceId(uuid)` → `DeviceId((b) => b..id = uuid)`, `LoginRequest((b) => b..username = u..password = p)`).
> `PushNotification*` is replaced by the generated `Notification`. `Authority` is a single generated type and
> `AuthUser.authority` is nullable. 65 enum constants are renamed (e.g. `SignUpFieldId.aDDRESS2` → `ADDRESS2`), a
> few model fields changed type (e.g. `AliasEntityId.entityType` is now `String`), and `DeviceApiControllerApi` and
> `SolutionControllerApi` are removed. Deep imports of removed files (`src/model/id/*`,
> `src/model/telemetry/query/**`, `src/model/login_models.dart`, ...) no longer work. See the
> [CHANGELOG](CHANGELOG.md) and the migration guide in the
> [thingsboard_client 5.0.0 CHANGELOG](https://pub.dev/packages/thingsboard_client/changelog#500).
>
> Code written for 4.2.x or earlier (`getUserService()`, ...) was already broken by 4.4.0 and must be migrated
> to the generated API.

## Migration

1. In `pubspec.yaml`, replace the dependency:

   ```yaml
   dependencies:
     thingsboard_client: ^5.0.0   # was: thingsboard_pe_client: ^4.x
   ```

2. Rewrite the imports:

   ```sh
   grep -rl "package:thingsboard_pe_client/" lib test | xargs sed -i 's#package:thingsboard_pe_client/thingsboard_pe_client.dart#package:thingsboard_client/thingsboard_client.dart#g; s#package:thingsboard_pe_client/#package:thingsboard_client/#g'
   ```

3. Fetch dependencies and check the result:

   ```sh
   flutter pub get && flutter analyze
   ```

The sed command above also rewrites deep imports (`package:thingsboard_pe_client/src/...`) to the same paths in
`thingsboard_client`. Deep imports of removed files must be replaced with
`package:thingsboard_client/thingsboard_client.dart`, which exports the replacement types.

## Stub libraries

`lib/src/**` is generated by `tool/gen_stubs.sh`: one deprecated re-export per library that exists both in
`thingsboard_pe_client` 4.4.x and in `package:thingsboard_client/src`. Files removed from `thingsboard_client`
(the handwritten telemetry and login models, the device and solution templates APIs) have no stub, so their deep
imports no longer work. This package is frozen at 5.0.0, so the stubs are generated once and do not need to be
regenerated for later `thingsboard_client` releases: users of the old package never import files that did not exist
in 4.4.x.

Please file issues at the [thingsboard_client issue tracker](https://github.com/thingsboard/dart_thingsboard_client/issues).
